# Theory and laboratory alignment

Total teaching: 14 hours = 120 minutes theory + 720 minutes practical.
The following theory allocation is a proposal, not an official timetable. Lecture slides are distributed separately by the instructor; the original presentations are not included in this repository.

| Lecture | Minutes | Selected concepts | Practical follow-up |
|---|---:|---|---|
| L14 Transport Layer Security | 40 | TLS 1.3 handshake, AEAD, ECDHE, PKI, SSH host trust, HTTPS metadata | Labs 01, 02 |
| L15 Application Layer Security | 40 | Email transport versus message protection, DNSSEC trust chain, DANE, SPF, DKIM, DMARC | Lab 01 worksheet; Lab 02 trust comparison |
| L16 Firewalls | 40 | Default-deny packet filtering, stateful inspection, DMZ, NIDS signatures and sensor placement | Labs 03, 04 |
| Total | 120 | | |

Use the supplied presentations as reference reading: L14_TransportLayer-Security-SSH-TLS_v2.0.pptx; L15_Application LayerSecurity-Email-DNS-v2.0.pptx; L16-Firewalling-v2.0.pptx. The two-hour class is a focused overview, not an exhaustive presentation of every slide. Assign remaining slides as independent reading.

## Practical coverage

Each lab retains 180 minutes and 25% of the laboratory grade. Short lecture-linked questions below replace portions of existing discussion or analysis time; they do not extend contact hours. SSH, S/MIME, DNSSEC deployment, DANE configuration and email authentication deployment are not full practical implementations in this version. No public network access is required.
